# Flow Diagnostics

Reproduces the three 2023 moments from Iacopo Bertelli's [Counterintuitive Flows in 2023 (Part 2 of 3)](https://www.linkedin.com/pulse/counterintuitive-flows-2023-part-2-3-iacopo-bertelli-baonf) &ndash; peak price convergence, peak simultaneous congestion, and peak counter-intuitive flow &ndash; using reusable functions from [`articles/common.py`](../common.py), then builds a counter-intuitive flow leaderboard with the same functions.

Open [`bertellis_flow_diagnostics.ipynb`](bertellis_flow_diagnostics.ipynb) and run top to bottom. See the root [README](../../README.md) for setup.

`media/` holds reference screenshots of the VoltPath dashboard for each reproduced moment.
