# Counter-Intuitive Flows in 2026

Examines counter-intuitive (CI) flows across European market regions in 2026, following Iacopo Bertelli's [Counterintuitive Flows in 2023 series](https://www.linkedin.com/pulse/counterintuitive-flows-2023-part-3-iacopo-bertelli-xjetf).

Open [`ci-flows-2026.ipynb`](ci-flows-2026.ipynb) and run top to bottom. See the root [README](../../README.md) for setup.

`media/` holds reference screenshots of the VoltPath dashboard for each highlighted moment; charts the notebook generates are written to a gitignored `output/`.
