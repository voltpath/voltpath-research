# Flamanville 3 EPR Grid Connection, 2024-12-21

Points the same reusable flow-analysis functions used in [bertellis-flow-diagnostics](../bertellis-flow-diagnostics/) at France's first new nuclear unit in 25 years connecting to the grid, to see whether it shows up mechanically in congestion, counter-intuitive flow, and convergence data &ndash; and why the answer is probably no.

Open [`flamanville_3_connection.ipynb`](flamanville_3_connection.ipynb) and run top to bottom. See the root [README](../../README.md) for setup.
