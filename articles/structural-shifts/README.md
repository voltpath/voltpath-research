# Structural Shifts, 2024&ndash;2026

Points the same reusable flow-analysis functions used in [bertellis-flow-diagnostics](../bertellis-flow-diagnostics/) at three verified structural changes to the European grid &ndash; Baltic states synchronisation, Flamanville 3's grid connection, and Core's Advanced Hybrid Coupling go-live &ndash; to see whether they show up mechanically in congestion, counter-intuitive flow, and convergence data.

Open [`structural_shifts_2024_2026.ipynb`](structural_shifts_2024_2026.ipynb) and run top to bottom. See the root [README](../../README.md) for setup.
