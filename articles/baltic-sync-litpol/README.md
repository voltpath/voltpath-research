# Baltic States Synchronisation and the LT&ndash;PL Link, 2025

Points the same reusable flow-analysis functions used in [bertellis-flow-diagnostics](../bertellis-flow-diagnostics/) at the Baltic states' 2025-02 desynchronisation from Russia's BRELL ring, to see whether it shows up mechanically in congestion, counter-intuitive flow, and convergence data &ndash; then traces the post-sync dip to one border, LT&ndash;PL (the LitPol Link), and checks Litgrid's own capacity-recovery plan against our own fetched data.

Open [`baltic_sync_litpol.ipynb`](baltic_sync_litpol.ipynb) and run top to bottom. See the root [README](../../README.md) for setup.
